# Решение проблемы госпитализации во время событий

## Проблема
Когда игрок погибает в шахте с критическими травмами, система принудительной госпитализации срабатывает даже во время событий (например, когда Харви находит игрока в шахте). Это прерывает событие и портит повествование.

## Решение 1: Отмена госпитализации во время событий

### Файл: `EventHandlers/PlayerEventHandler.cs` (строки 146-164)

**Что изменили:**
```csharp
// БЫЛО:
if (_config.ForceHospitalization && _buffManager.HasAnyBuff(InjurySets.Severe.ToArray()))
{
    _hospitalizationManager.StartForcedHospitalization(injury, harvey);
    return;
}

// СТАЛО:
if (_config.ForceHospitalization && _buffManager.HasAnyBuff(InjurySets.Severe.ToArray()))
{
    // Проверяем, что не идёт событие
    if (Game1.eventUp || !Context.IsPlayerFree)
    {
        _monitor.Log("⏸️ Госпитализация отложена - идёт событие", LogLevel.Debug);
        return;
    }
    
    _hospitalizationManager.StartForcedHospitalization(injury, harvey);
    return;
}
```

**Как работает:**
- `Game1.eventUp` - проверяет, идёт ли в данный момент событие
- `Context.IsPlayerFree` - проверяет, свободен ли игрок для действий
- Если хотя бы одно условие истинно → госпитализация откладывается
- После завершения события система снова начнёт проверять условия

**Когда Харви НЕ отменяет госпитализацию:**
- После события, если у игрока всё ещё критические травмы
- Когда игрок заходит в шахты/пещеры в критическом состоянии
- При смене локации (если не в событии)

**Когда Харви отменяет/откладывает госпитализацию:**
- Во время любого события (event)
- Во время кат-сцен
- Когда игрок в диалоге или меню
- Во время события спасения в шахте

## Решение 2: Интерактивная госпитализация

### Файл: `Managers/HospitalActivityManager.cs` (новый)

**Что добавили:**
Система интерактивных активностей во время госпитализации, чтобы не было скучно.

**Типы активностей:**
1. **checkVitals** - Харви проверяет пульс и показатели
2. **bringWater** - приносит воду (+15 энергии)
3. **adjustPillow** - поправляет подушку
4. **readChart** - изучает медицинскую карту
5. **conversation** - случайные беседы
6. **holdHand** - держит за руку (+5 здоровья, только для встречающихся/женатых)
7. **checkBandage** - проверяет повязку
8. **bringMedicine** - даёт лекарство (+10 здоровья)
9. **comfort** - успокаивает
10. **checkTemperature** - измеряет температуру

**Частота активностей:**
- Каждые 20 минут игрового времени
- Случайная активность из доступных
- Разные диалоги в зависимости от отношений с Харви

**Интеграция:**
```csharp
// TimeEventHandler.cs - вызов каждые 10 минут
_hospitalActivityManager.UpdateHospitalActivities(_hospitalizationManager);
```

## Решение 3: Автоматическая выписка

### Файл: `Managers/HospitalizationManager.cs` (метод HandleWarpAttempt)

**Как работает выписка:**

1. **Минимальный срок:** 120 минут игрового времени (по умолчанию)
   - Настраивается в `config.json` → `MinHospitalStayMinutes`

2. **Проверка при попытке уйти:**
   ```csharp
   if (CanDischarge()) // Прошло достаточно времени?
   {
       Discharge(); // Автоматическая выписка
       // + сброс активностей
       // + прощальный диалог от Харви
       return false; // Разрешаем покинуть больницу
   }
   ```

3. **Если срок не прошёл:**
   - Игрок телепортируется обратно в палату
   - Харви показывает строгую реакцию
   - Звук "debuffHit"

**Диалог при выписке:**
```
Харви: "Ты молодец. Показатели в норме.$h
        Но будь осторожнее в следующий раз!$s"
```

## Как это всё работает вместе

### Сценарий 1: Игрок погибает в шахте с событием
```
1. Игрок получает критическую травму в шахте
2. Срабатывает событие "eventHarveyMineRescue" (Content Patcher)
3. Во время события: Game1.eventUp = true
4. Система госпитализации видит событие и откладывает принудительную госпитализацию
5. Событие проигрывается полностью: Харви находит, спасает, везёт в больницу
6. После события игрок уже в клинике, травма может быть вылечена
```

### Сценарий 2: Игрок идёт в шахту с критической травмой БЕЗ события
```
1. Игрок имеет критический бафф (buffBadlyHurt и т.д.)
2. Игрок входит в шахту (Location = MineShaft)
3. HandleMinesLogic() проверяет критические травмы
4. Событие не идёт (Game1.eventUp = false)
5. Срабатывает принудительная госпитализация:
   - StartForcedHospitalization()
   - Телепорт в больницу
   - Диалог от Харви
6. Начинается интерактивная госпитализация:
   - Каждые 20 минут - активность
   - Харви ухаживает за игроком
7. Через 120 минут (MinHospitalStayMinutes):
   - Игрок может покинуть больницу
   - Автоматическая выписка
   - Прощальный диалог
```

### Сценарий 3: Игрок пытается сбежать из больницы
```
1. Игрок госпитализирован (IsHospitalized = true)
2. Попытка перемещения в другую локацию (не клинику)
3. HandleWarpAttempt() проверяет:
   - Прошло ли MinHospitalStayMinutes?
   
   ЕСЛИ НЕТ:
   - Блокирует варп
   - Телепортирует обратно в палату
   - Харви: "Назад в палату. Я не обсуждаю это.$a"
   
   ЕСЛИ ДА:
   - Разрешает варп
   - Автоматическая выписка (Discharge)
   - Сброс активностей (Reset)
   - Харви: "Ты молодец. Показатели в норме.$h"
```

## Настройки в config.json

```json
{
  "ForceHospitalization": true,          // Включить принудительную госпитализацию
  "MinHospitalStayMinutes": 120,         // Минимальный срок (в игровых минутах)
  "HospitalLocationName": "Hospital",    // Название локации больницы
  "HospitalBedX": 20,                    // Координата X кровати
  "HospitalBedY": 5                      // Координата Y кровати
}
```
