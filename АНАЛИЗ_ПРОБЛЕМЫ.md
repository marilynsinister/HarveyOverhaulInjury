# Анализ проблемы: События и госпитализация

## 🔴 ПРОБЛЕМА ОБНАРУЖЕНА

### Текущая последовательность событий:

```
1. Игрок теряет сознание в шахте (health = 0)
   ↓
2. ИГРА телепортирует игрока ДОМОЙ (стандартная механика Stardew Valley)
   ↓
3. PassOutHandler.OnPlayerWarped срабатывает
   → Применяет buffBadlyHurt (строка 60)
   ↓
4. Игрок ДОМА с критической травмой
   ↓
5. Событие eventHarveyMineRescue требует:
   - Location = Mine ❌ (игрок уже дома!)
   - buffBadlyHurt ✅
   ↓
6. Событие НЕ СРАБАТЫВАЕТ!
```

### Почему событие не сработает?

**Файл:** `eventsMineRescue.json`
```json
"eventHarveyMineRescue/GameStateQuery PLAYER_HAS_BUFF Current buffBadlyHurt/
GameStateQuery PLAYER_NPC_RELATIONSHIP Current Harvey Dating Married/
GameStateQuery !PLAYER_HAS_SEEN_EVENT Current eventHarveyMineRescue"
```

**Проблема:** В условиях события НЕТ проверки локации, но событие добавлено в `Data/Events/Mine`!

Это означает событие сработает только когда:
- Игрок ВХОДИТ в локацию Mine
- У него есть нужные баффы
- Выполнены условия

**НО:** После обморока игрок телепортируется ДОМОЙ, не в шахту!

## 🔍 Детальный анализ

### Что происходит после обморока в шахте?

**Stardew Valley стандартная механика:**
```csharp
// Игра автоматически телепортирует игрока:
if (health <= 0 && inMine) {
    // Телепорт домой на следующий день
    warpToFarmHouse();
    newDay();
}
```

**Наш PassOutHandler (строки 124-130):**
```csharp
else if (Game1.player.health <= 0)
{
    _stateManager.State.WasPassedOut = true;
    _stateManager.State.LastPassedOutHealth = 0;
    _stateManager.State.LastPassedOutLocation = Game1.currentLocation?.NameOrUniqueName ?? "";
    
    _monitor.Log($"Обнаружен обморок от урона (health=0)", LogLevel.Info);
}
```

Сохраняет локацию обморока: `LastPassedOutLocation = "Mine"` или "UndergroundMine"

**Потом (строки 52-64):**
```csharp
if (isDatingOrMarried && 
    _stateManager.State.LastPassedOutHealth >= 0 && 
    _stateManager.State.LastPassedOutHealth <= 10 &&
    !Helpers.GameUtils.HasConversationTopic("topicBadlyHurt") && 
    !Game1.player.hasBuff("buffBadlyHurt"))
{
    _injuryManager.ApplyBadlyHurtSafe(); // Применяет бафф
}
```

**Результат:** 
- Игрок ДОМА
- У него есть buffBadlyHurt
- Но событие требует локацию Mine!

## 💡 РЕШЕНИЯ

### Вариант 1: Событие на ферме (РЕКОМЕНДУЕТСЯ)
Создать событие, которое срабатывает на следующий день после обморока в шахте.

**Файл:** `Data/Events/FarmHouse` или `Data/Events/Hospital`
```json
"eventHarveyMineRescueAftermath/
GameStateQuery PLAYER_HAS_CONVERSATION_TOPIC Current topicMineDeath/
GameStateQuery PLAYER_NPC_RELATIONSHIP Current Harvey Dating Married/
Time 600 800"
```

**Сценарий:**
- Игрок просыпается после обморока
- Харви уже здесь, заботится о нём
- Флэшбэк: "Вчера в шахте..."
- Реакция Харви

### Вариант 2: Триггер вместо события
Использовать TriggerActions для запуска специального события.

**Файл:** `triggersCare.json`
```json
{
    "Id": "{{ModId}}_triggerMineDeathRescue",
    "Trigger": "DayStarted",
    "Condition": "PLAYER_HAS_CONVERSATION_TOPIC Current topicMineDeath, 
                  PLAYER_NPC_RELATIONSHIP Current Harvey Dating Married",
    "Actions": [
        "spacechase0.SpaceCore_PlayEvent eventHarveyMineRescueMemory"
    ]
}
```

### Вариант 3: Изменить PassOutHandler
Вместо применения баффа, добавить топик для события.

**В PassOutHandler.OnPlayerWarped (после строки 60):**
```csharp
// Если погиб в шахте - добавляем топик
if (_stateManager.State.LastPassedOutLocation.Contains("Mine"))
{
    _dialogueManager.AddTopic("topicMineDeath", 1);
    _monitor.Log("💀 Добавлен топик обморока в шахте", LogLevel.Info);
}
```

### Вариант 4: Событие при первом входе в клинику
После обморока игрок может зайти к Харви - там событие.

**Файл:** `Data/Events/Hospital`
```json
"eventHarveyAfterMineDeath/
GameStateQuery PLAYER_HAS_CONVERSATION_TOPIC Current topicMineDeath/
GameStateQuery PLAYER_NPC_RELATIONSHIP Current Harvey Dating Married"
```

## 🎯 РЕКОМЕНДАЦИЯ

**Комбинированный подход:**

1. **Убрать событие из Mine** (оно там не нужно, не сработает)
2. **Добавить топик при обмороке в шахте** (в PassOutHandler)
3. **Создать событие на следующий день** (FarmHouse или Hospital)
4. **Сохранить госпитализацию** (для случаев, когда игрок идёт в шахту УЖЕ раненым)
