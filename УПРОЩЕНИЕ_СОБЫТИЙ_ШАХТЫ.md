## 📋 Причина изменений

События теперь запускаются **программно** через `TriggerEventByName()` в `PassOutHandler.cs`, где все условия проверяются в коде C#:

### Условия для eventHarveyMineRescue (в коде):
```csharp
if (hasSeriousInjuries && isDatingOrMarried && healthPercent <= 15f)
{
    if (!Game1.player.eventsSeen.Contains("eventHarveyMineRescue"))
    {
        TriggerEventByName("eventHarveyMineRescue", "Mine");
    }
}
```

**Проверяемые условия:**
- ✅ `hasSeriousInjuries` - наличие серьёзных ран (buffBadlyHurt, buffConcussion, buffFracturedBone, buffShrapnelWounds, buffBurnWounds)
- ✅ `isDatingOrMarried` - отношения Dating или Married с Харви
- ✅ `healthPercent <= 15f` - здоровье <= 15%
- ✅ `!eventsSeen.Contains("eventHarveyMineRescue")` - событие не было просмотрено

---

### Условия для eventHarveyMinorMineRescue (в коде):
```csharp
else if (hasMinorInjury && harveyFriendship >= 500 && harveyFriendship < 1000 && healthPercent <= 15f)
{
    if (!Game1.player.eventsSeen.Contains("eventHarveyMineRescue") 
        && !Game1.player.eventsSeen.Contains("eventHarveyMinorMineRescue"))
    {
        TriggerEventByName("eventHarveyMinorMineRescue", "Mine");

}
```

**Проверяемые условия:**
- ✅ `hasMinorInjury` - наличие buffBadlyHurt
- ✅ `harveyFriendship >= 500 && < 1000` - дружба 2-3 сердца (500-999)
- ✅ `healthPercent <= 15f` - здоровье <= 15%
- ✅ События не были просмотрены ранее
