# Проверки гибели и восстановления

Сборка модов без установки в игру:

```powershell
dotnet build HarveyOverhaulInjury/HarveyOverhaulInjury.csproj --no-restore -p:EnableModDeploy=false -p:EnableGameDebugging=false
dotnet run --project HarveyOverhaulInjury/tests/HospitalLifecycle/HospitalLifecycle.csproj
```

Используются собранные Debug DLL Core и Injury и установленная игра. Сохранения
не загружаются и не изменяются. Путь игры задаётся в тестовом csproj.

51 проверка охватывает смену настоящих объектов DialogueBox/ItemListMenu,
завершённые и прерванные реплики, смену/конец события, постановку у переставленной
кровати, единственный домашний визит, повторное поступление, течение срока,
сон без двойного зачёта минут, утреннюю выписку, очереди сцен и маршруты спасения.

Это проверки кода на объектах установленной игры без графического игрового
цикла. Визуальную постановку, ввод и взаимодействие с остальными модами
нужно дополнительно проверить на отдельном игровом сохранении.
