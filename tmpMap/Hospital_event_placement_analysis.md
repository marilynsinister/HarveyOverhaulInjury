# Hospital — анализ зоны события (после спасения из шахты)

> Источник карты: `tmpMap/Hospital.tmx` (SVE Hospital, 24×20).  
> Дата анализа: 2026-05-23.  
> Назначение: staging сцены «Харви уложил игрока на кровать и наблюдает» после `changeLocation Hospital`.  
> Это **не** event script — только координаты, коллизии и камера.

---

## Hospital — анализ зоны события

### Размер карты

| Параметр | Значение |
|----------|----------|
| **width** | 24 тайла |
| **height** | 20 тайлов |
| **tilesize** | 16×16 px |

**Свойства карты:** `DayTiles` (анимация кроватей на тайлах Front), `Doors`, `NightTiles`, варпы `10 20 → Town`, `10 1 / 9 1 → HarveyRoom`.

### Слои

| Слой | Назначение |
|------|------------|
| **Back** | Пол, ковёр (872), коридоры |
| **Back2** | Подложка (Draw=Back) |
| **Buildings** | **Коллизии**: кровати (1100/1101, 843/844/875…), стены, столы, двери (839) |
| **Front** | Постель, одеяла, декор; часть тайлов блокирует обход |
| **Front2 / Front3** | Доп. декор (Draw=Front) |
| **Paths** | NPC-маршруты (тайл 2185) |
| **AlwaysFront** | Верхний декор |

### Правила коллизий

- **Buildings ≠ 0** → непроходимо (кровать, стена, мебель, дверной косяк).
- **Кровать в событии:** тайл кровати **заблокирован** — игрок ставится через `ignoreCollisions` + `positionOffset` + lying-анимация (`4 5`).
- **Front ≠ 0** → одеяло/изголовье; NPC часто **может стоять** на клетке с Front (события), но `move` через них ненадёжен.
- **Back ≤ 1** без Buildings → void / край карты.

### Зона палаты

На карте **три** клинически значимых зоны; для mine rescue используются **две верхние**.

#### 1. Палата B — основная кровать (major + `HospitalBedX/Y`)

**Правый верхний блок, кровать «главная» для мода.**

```
        x: 18  19  20  21  22
y=3        █   █   █   █   █   ← стена/шкафы (Buildings)
y=4        .   █   █   █   █   ← изголовье (875, 1068, 1069…)
y=5        f   f   B   B   █   ← B = кровать 1100/1101; игрок (20,5)
y=6        f   f   .   f   f   ← проход южнее кровати
y=7        █   █   .   █   █
y=8        f   f   f   f   .

B = непроходимая кровать   f = Front (одеяло)   . = пол
```

| Элемент | Координаты | Buildings | Примечание |
|---------|------------|-----------|------------|
| Изголовье / рама | (19,4)–(22,4) | 875, 1068, 1069… | Непроходимо |
| **Тайл кровати (игрок)** | **(20, 5)** | **1100** | `ModConfig` + `eventHarveyMineRescue`; Path 2185 |
| Кровать (голова) | (21, 5) | 1101 | Соседний тайл кровати |
| Пол у изголовья | (20, 6), (20, 7) | 0 | Подход Харви с юга |
| **Харви у постели** | **(19, 5)** | 0, Front=1136 | Используется в CP-событии |
| Западнее | (18, 5), (18, 6) | 0, Front | Запасная стойка |

**`positionOffset farmer 32 -52`** при (20, 5): сдвиг спрайта на одеяло (lying frames `4 5`, `faceDirection 2`).

#### 2. Палата A — вторая кровать (minor rescue)

**Центр карты, открытый пол у кровати.**

```
        x: 12  13  14  15  16  17
y=5        █   .   █   █   .   █
y=6        █   .   .   .   .   █   ← ядро: (13–16, 6)
y=7        f   f   .   .   .   █
```

| Элемент | Координаты | Примечание |
|---------|------------|------------|
| **Игрок (minor)** | **(14, 6)** | Пол, проходимо; `eventHarveyMinorMineRescue` |
| **Харви (minor)** | **(15, 6)** | Восточнее игрока; Path 2185 |
| Западнее | (13, 6) | Запасная позиция игрока |
| Север | (14, 5), (16, 5) | Частично открыто |

Подходит для сцены «сидит / осмотр у кровати», без lying-offset.

#### 3. Нижний зал (y=14–18) — не для mine rescue

Кровати **843/844/875** в рядах y=15–17 (x≈11–15). Используется визуально как общий стационар; **текущие события и `HospitalBedX/Y` сюда не ведут**.

### Лучшая постановка сцены

#### Major (`eventHarveyMineRescue` — реанимация)

1. **Где появляется игрок:** **(20, 5)**, направление **2**; `ignoreCollisions` + `positionOffset 32 -52` + lying `animate 4 5` — визуально на правой кровати.
2. **Где стоит Харви:** **(19, 5)**, направление **1** — слева от кровати, лицом к игроку.
3. **Откуда Харви подходит:** `warp` на **(19, 5)** или **(20, 6)** + короткий `move` на север; не вести через (20,5) и мебель y=3–4.
4. **Где фокус камеры:** **(14, 6)** — широкий кадр палаты B; после реплик можно сместить на **(19, 5)** для крупного плана.
5. **Как закончить сцену:** `globalFade` / `viewport -1000 -1000` → `end` или оставить игрока на кровати для `HospitalizationManager` (тот же **20, 5**); `ambientLight 180 180 180` — яркая клиника.

#### Minor (`eventHarveyMinorMineRescue` — осмотр)

1. **Где появляется игрок:** **(14, 6)** — пол у палаты A (сидит/стоит).
2. **Где стоит Харви:** **(15, 6)** — на один тайл восточнее, лицом влево (**3**) к игроку.
3. **Откуда Харви подходит:** warp **(15, 6)** или с **(9, 6)** (Path) по открытому полу y=6.
4. **Где фокус камеры:** **(14, 6)**.
5. **Как закончить сцену:** `globalFade` → `end`; при госпитализации fallback лучше варп на **(20, 5)** (единая кровать мода).

### Жёсткие ограничения staging

1. **Major:** не ставить игрока на (20,5) без `ignoreCollisions` и offset — тайл кровати заблокирован.
2. **Харви:** не использовать (20,5), (21,5), (19,4) для стояния/ходьбы.
3. **Камера:** не центрировать на (20,5) alone — обрезает комнату; **(14,6)** или **(15,5)** лучше.
4. **Не путать** с нижним залом (y≥14) — там другие кровати 843/844.
5. **Maru** в major-событии: появляется по скрипту в той же палате — держать в зоне x=17–21, y=5–7, не на дверях.
