# Mine — анализ зоны события (спасение Харви)

> Источник карты: `tmpMap/Mine.tmx` (вход в шахту, SVE/vanilla layout).  
> Дата анализа: 2026-05-23.  
> Назначение: постановка персонажей и камеры для событий `eventHarveyMineRescue` / `eventHarveyMinorMineRescue`.  
> Это **не** event script — только координаты и коллизии.

## Слои

| Слой | Тип | Назначение для постановки |
|------|-----|---------------------------|
| **Back** | tile layer | Пол/земля; `0` = пустота за картой |
| **Buildings** | tile layer | **Коллизии**: любой тайл ≠ 0 блокирует ходьбу |
| **Front** | tile layer | Декор поверх пола; тайлы **≥ 85** — обрывы, пороги, риск блокировки NPC |
| **Paths** | tile layer | NPC-маршруты (в зоне события почти пустой) |
| **Back** (objectgroup) | objects | Пустая группа |
| **Buildings** (objectgroup) | objects | Интерактивы: лифт, спуск, вагонетка |
| **Front** (objectgroup) | objects | Пустая |
| **Paths** (objectgroup) | objects | Пустая |

### Правила коллизий (для скриптов/ручной проверки)

- **Buildings ≠ 0** → непроходимо (стены, лифт, вагонетка, спуск).
- **Back = 0 и Buildings = 0** → void / край карты.
- **Front ≥ 85** → декор/обрыв; NPC может застрять при `move` на юг (y ≥ 11).

## Рекомендуемая постановка

- **Игрок:** **(17, 7)**, направление **2 (вниз)**.
- **Харви появляется:** **(17, 10)** или `warp` с **(1000, 1000)**; запасно (16, 10) / (18, 10).
- **Харви идёт:** `move Harvey 0 -2 0` → **(17, 8)**; не вести на **y ≥ 11**.
- **Камера:** `viewport 17 7 true`.
- **Затемнение:** `ambientLight 40 40 40` + `fade true` в начале; `fade false` после появления Харви; `globalFade` перед `changeLocation Hospital`.

### Жёсткие ограничения

1. Не ставить NPC на **y ≥ 11**.
2. Не использовать **x ≤ 13** и **x ≥ 22** для движения.
3. Не вести `move` через **(23, 9)** и вагонетку **(11–12, 10)**.
4. Вертикаль **x = 17**, **y = 6–10** — самый надёжный коридор.
