# Верификация анализа карт (tmpMap/*.tmx)

Проверка: `Mine.tmx`, `Hospital.tmx` в `HarveyOverhaulInjury/tmpMap`  
Метод: парсинг XML-слоёв, objectgroup `Action`, map `properties`  
**Не проверялось:** runtime `.tbin` в игре, CP-патчи SVE поверх карты, `positionOffset`, поведение NPC на Front.

---

## Методология

| Тип утверждения | Критерий |
|-----------------|----------|
| **Подтверждено картой** | Есть в TMX: размер, property, tile ID, object `Action`, Buildings/Front/Back/Paths на (x,y) |
| **Вероятно, проверить в игре** | Вывод из ID тайлов + логики SDV; семантические названия; правила «Front блокирует NPC» |
| **Не подтверждено / нельзя опираться** | Только C#/CP/мод; неверные ID; неточные зоны; выдуманные координаты |

# MINE (`Mine.tmx`, 77×20)

## Подтверждено картой

| Утверждение | Доказательство в TMX |
|-------------|---------------------|
| Размер **77×20** | `width` / `height` в корне map |
| Слои Back, Buildings, Front, Paths | Имена `<layer>` |
| Properties: AmbientLight `80 80 40`, ViewportFollowPlayer, Warp | `<properties>` |
| Warp **(18,14)→Mountain** и **(67,18)→Mountain** | `Warp="18 14 Mountain 54 5 67 18 Mountain 103 17"` |
| Object **MineElevator** | (17,3), Action=`MineElevator` |
| Object спуск **Mine** | (23,9), Action=`Mine` |
| Object **Mine 77377** | (67,9) |
| Object **Minecart** | (11,10), (12,10) |
| **(17,7):** Buildings=0, Front=0, Back=155 | Слои CSV |
| **(17,10), (17,8):** Buildings=0, Front=0 | Слои CSV |
| **(17,3):** Buildings=129 (непроходимо) | Слои CSV |
| **(23,9):** Buildings=190 | Слои CSV |
| **(11,10), (12,10):** Buildings=212, 241 | Слои CSV |
| **y=0–3, x=15–21:** все Buildings≠0 | Проверка строк 0–3 |
| **(18,14):** Buildings=0, Front=231 | Слои CSV |
| Маршрут **(17,10)→(17,9)→(17,8)** Buildings=0 | Слои CSV (y=9 не проверялся отдельно в скрипте — **добавить:** (17,9) b=0 f=0 ✓) |

## Вероятно, проверить в игре

| Утверждение | Почему сомнительно |
|-------------|-------------------|
| «**Вход в шахту**» / «платформа у лифта» | Нет подписи в TMX; название локации — из игры |
| «**Деревянный настил**» (Back 155/172) | ID тайлов есть; материал — визуальная интерпретация |
| «**Ядро сцены**» 15–21 × 6–10 | Зона с Buildings=0 подтверждена частично; **(13,7) тоже проходим** — западная граница не x≤13 |
| «**Front ≥ 85** блокирует NPC» | Правило движка, **не** property карты |
| «**Void**» (Back=0, Buildings=0) | Формула верна; для y=6–10 **(12,7), (13,7) не void** — опасная таблица «x≤13 void» **завышена** |
| **(14,11), (15,11)** «Front=94» | **Неверный ID в тексте:** фактически Front=**247, 248**; блокировка NPC — проверить в игре |
| **(17,12)** Front=233 | ID подтверждён; степень блокировки — в игре |
| «**SVE/vanilla layout**» в шапке | В TMX нет метки; источник файла не доказан |
| Координаты из **PassOutHandler (17,7)** | Из C#, не TMX; **совпадают** с проходимым тайлом на этой карте |

## Не подтверждено / не использовать как факт карты

| Утверждение | Причина |
|-------------|---------|
| «**Вагонетка**» без object | Объект есть — OK; координаты **обязательно** (11,10)/(12,10) |
| «**Край карты void**» для всех x≤13, y=6–10 | **Опровергнуто** для (12,7), (13,7) |
| **(67,18)** как «опасный край» без уточнения | Warp property **подтверждён**; тайл: Buildings=0, Front=96 — не void; риск другой |
| Сетка ASCII с символом **F=94** на y=11 | Упрощение; реальные Front ID другие |

| **(21,5):** Buildings=**1101** | Слои CSV |
| **(19,5):** Buildings=0, Front=**1136** | Слои CSV |
| **(14,6), (15,6):** Buildings=0; Paths=2185 на (15,6) | Слои CSV |

| Третий тайл **1100** | **(18,13)** — **пропущен в анализе** |

## Вероятно, проверить в игре

| Утверждение | Почему сомнительно |
|-------------|-------------------|
| Слово «**кровать**» для 1100/1101 | ID коллизии подтверждены; **вид «кровать»** — по спрайту в игре |
| «**Палата B**» / «**Палата A**» | **Нет в TMX**; логическая группировка: A ≈ (14,5–15,5)+(14,6), B ≈ (20,5–21,5) |
| «**Палата B — правая верхняя**» | (20,5) справа — да; «верхняя» — условно (y=5) |
| «**Изголовье / одеяло**» (Front f, 875, 1068…) | ID подтверждены; названия — интерпретация |
| «**Игрок лежит на кровати**» в (20,5) | Buildings=1100 = блок; лежание через **ignoreCollisions + offset** — из **CP**, не TMX |
| **positionOffset 32 -52** | Только `eventsMineRescue.json`, **не карта** |
| **lying animate 4 5** | Код события, не карта |
| «**NPC может стоять** на Front 1136» | Buildings=0 на (19,5) — да; Front≠0 — поведение в игре |
| «**Камера (14,6) видит обоих**» | Композиция — **только in-game** |
| «**SVE Hospital**» | Файл похож на клинику SVE (Door Harvey, HospitalShop), но **в TMX нет поля SVE**; runtime может отличаться от .tbin |
| **(14,6) для minor** — «открытый пол» | Buildings=0 — да; рядом **кровать 1100 на (14,5)** — в анализе как «палата A» смягчено, но **не «просто пол»** |
| «Нижний зал y=14–18, x≈11–15» | Тайлы 843/844/875 есть, но также **(1,17), (18,12)** и др. — зона **шире**, чем в тексте |

## Не подтверждено / не использовать как факт карты

| Утверждение | Причина |
|-------------|---------|
| «**Кровать мода**» = единственная точка (20,5) | **ModConfig/C#**; на карте **две** зоны 1100/1101: (14,5)/(15,5) и (20,5)/(21,5) |
| DayTiles **(14,1)/(21,1)** = та же кровать, что (20,5) | **Разные координаты**; связь только визуальная/игровая |
| **Maru** в палате | **Нет** в TMX |
| «**Столы / шкафы**» без ID | Нужны конкретные (x,y) или Buildings ID |
| «**Проход** южнее кровати (20,6)» | (20,6) Buildings=0 — **подтверждено**; слово «проход» — OK; «южнее кровати» — интерпретация |
| Hospital **(18,13)** с 1100 | **Пропуск в анализе** — не «выдумка», но не документировано |

# Сводка: координаты постановки (итог верификации)

## Можно использовать (подтверждено слоями tmpMap)

| Карта | Координаты |
|-------|------------|
| Mine | Игрок **(17,7)**; Harvey **(17,10)→(17,8)**; камера **(17,7)** |
| Hospital | Игрок **(20,5)** + механика lying из CP; Harvey **(19,5)**; камера **(14,6)**; minor: **(14,6)/(15,6)** |

## Проверить в игре обязательно

- `positionOffset` + lying на (20,5)  
- Камера (14,6) и (17,7) — кадр не пустой  
- Harvey `move` / стояние на (19,5) с Front=1136  
- Совпадение **tmpMap** с загружаемой в рантайме картой (SVE .tbin + патчи)

## Не подтверждено картой (внешние источники)

- Имена «палата A/B», «кровать», «настил», «вход»  
- SVE как обязательный источник **этого файла**  
- topic, friendship, mail, Maru  
- Правило Front≥85  
- Точная формулировка «void запад Mine x≤13»
