# ✅ Исправление логики: События после обморока в шахте

## 🔴 Проблема (обнаружена)

### Старая логика (НЕ РАБОТАЛА):
```
1. Игрок теряет сознание в шахте (health = 0)
2. Игра телепортирует домой (стандартная механика)
3. PassOutHandler применял buffBadlyHurt
4. Событие в Mine НЕ срабатывало (игрок уже дома!)
5. Драматическая сцена ПРОПУСКАЛАСЬ ❌
```

---

## ✅ Решение (ИСПРАВЛЕНО)

### Новая логика:

#### Сценарий 1: Обморок в шахте → Событие на следующий день

```
ДЕНЬ 1 (обморок):
──────────────────
1. Игрок теряет сознание в шахте (health = 0)
   
2. PassOutHandler.TrackPassOut():
   - WasPassedOut = true
   - LastPassedOutHealth = 0
   - LastPassedOutLocation = "UndergroundMine"
   
3. Игра телепортирует домой (новый день)

4. PassOutHandler.OnPlayerWarped():
   - Проверяет: LastPassedOutLocation.Contains("Mine")
   - ✅ Да! Был обморок в шахте
   - Добавляет топик: topicMineDeathRescue
   - НЕ применяет buffBadlyHurt сразу
   
5. Игрок засыпает

ДЕНЬ 2 (событие):
──────────────────
6. Игрок просыпается дома (FarmHouse)

7. Content Patcher проверяет условия события:
   - ✅ topicMineDeathRescue существует
   - ✅ Dating/Married с Харви
   - ✅ Событие не было показано
   - ✅ Время 6:00-10:00
   
8. Событие "eventHarveyMineRescueMemory" срабатывает:
   - Харви у кровати
   - "Наконец-то ты проснулась!"
   - Флэшбэк вчерашнего спасения
   - Эмоциональные диалоги
   - Применение buffHarveyIntensiveCare
   - Удаление топика topicMineDeathRescue
   - +50-85 дружбы
   - Письмо на почту

9. События НЕ ПРОПУЩЕНЫ! ✅
```

## 📝 Изменения в коде

### 1. PassOutHandler.cs (строки 50-75)

**Было:**
```csharp
if (isDatingOrMarried && критическое_здоровье) {
    _injuryManager.ApplyBadlyHurtSafe(); // Сразу применяет бафф
    Game1.addHUDMessage(...);
}
```

**Стало:**
```csharp
if (isDatingOrMarried && критическое_здоровье) {
    bool wasInMine = _stateManager.State.LastPassedOutLocation.Contains("Mine");
    
    if (wasInMine) {
        // Для обморока в шахте - только топик
        _dialogueManager.AddTopic("topicMineDeathRescue", 1);
        _monitor.Log("💀 Топик обморока в шахте добавлен");
    } else {
        // Для других мест - обычная травма
        _injuryManager.ApplyBadlyHurtSafe();
        Game1.addHUDMessage(...);
    }
}
```

### 2. eventsMineRescue.json

**Было:** События в `Data/Events/Mine` (не работало!)

**Стало:** События в `Data/Events/FarmHouse` и `Data/Events/Hospital`

**3 события:**

#### A) eventHarveyMineRescueMemory (FarmHouse)
- **Условия:** topicMineDeathRescue + Dating/Married + 6:00-10:00
- **Сюжет:**
  - Харви у кровати
  - Флэшбэк спасения
  - Эмоциональный диалог
  - Выбор ответа (3 варианта)
- **Награда:** +75-85 дружбы + письмо + лечение

#### B) eventHarveyMinorMineInjury (FarmHouse)
- **Условия:** topicMineDeathRescue + 2-4 сердечка
- **Сюжет:**
  - Харви проверяет состояние
  - Осматривает травму
  - Просит быть осторожнее
- **Награда:** +40 дружбы + лечение

#### C) eventHarveyClinicAfterMine (Hospital)
- **Условия:** topicMineDeathRescue + если игрок пришёл в клинику
- **Сюжет:**
  - Харви строго отчитывает
  - "Ты должна отдыхать!"
  - Отводит домой
- **Награда:** +60 дружбы + усиленное лечение
