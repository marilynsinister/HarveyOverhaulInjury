# Матрица реакций жителей долины

Контент-дизайн **дополнительных** реплик NPC на события HarveyOverhaulInjury и HarveyStressMeter.  
Опирается на [`npc-reactions-source-audit.md`](npc-reactions-source-audit.md). **Новых механик нет** — только ключи диалогов через существующие topics / buffs / quests / relationship.

---

## Принципы

| Правило | Как соблюдать |
|---------|----------------|
| Дополнение, не замена | Ключи — **отдельные topic-entries** (`topicDeepCuts`, `HarveyMod_RecoveryPlanStarted`…), Priority `Late`; без перезаписи seasonal/heart dialogue |
| Характер NPC | Тон, лексика и длина реплики = канон персонажа; не «переписывать» всех под медсестёр |
| Разная забота | Кто-то замечает, кто-то шутит, кто-то молчит, кто-то ворчит — не единый хор сочувствия |
| Без токсичности | Нет сплетен, стыда, «все обсуждают фермера», намёков на слабость как сплетню |
| Романтика — у Харви | Другие NPC не флиртуют, не соперничают, не вторгаются в медицинскую близость; максимум — дружеский подкол или тёплое «он за тобой присматривает» |
| Дети | Jas и Vincent — без страшных деталей, без медицинского жаргона, без ночных кошмаров |
| Язык | Русский, мягкая атмосфера SDV, уважительное «вы» у старших / незнакомых, «ты» у близких по hearts |

### Формат будущих ключей (для авторов CP)

```
Characters/Dialogue/{NpcName} → ключ = существующий topic/buff gate
When: HasConversationTopic / HasBuff / HasQuest + Hearts tier + !FestivalDay
```

### Легенда колонок

| Колонка | Значение |
|---------|----------|
| **Тип** | замечание / быт / шутка / ворчание с заботой / профессионально / поддержка / дистанция / — |
| **Тон** | тёплый / сухой / неловкий / строгий / игривый / сдержанный |
| **Уместно** | hearts, локация, тяжесть состояния, погода |
| **НЕуместно** | когда молчать или оставить ваниль |
| **Реплики** | 2–5 черновиков; в игре — `$1` / `$c` для повторов |

## Сводка: состояние → CP-safe gates

| № | Состояние | Gates (из аудита) |
|---|-----------|-------------------|
| 1 | Недавняя травма | `HasConversationTopic topic*` / `HasBuff buff*` (кроме `buffHurt` — отдельно mild/severe) |
| 2 | После лечения у Харви | `topicFirstTreatmentComplete`, `topicTreatmentCompleted`, `HasBuff buffHarveyTreatment` / cure buffs |
| 3 | Нарушил recovery plan | `HarveyMod_RecoveryPlanViolated*` (тип/severity) |
| 4 | Соблюдает recovery plan | `HarveyMod_RecoveryPlanStarted`, `HarveyMod_RecoveryPlanCompleted_*`, `HarveyMod_RecoveryPlanSoftTone` |
| 5 | Спасён из шахты | `topicMineInjuryRescue`, `PLAYER_HAS_SEEN_EVENT eventHarveyMineRescue*`, `mailHarveyAfterMineRescue` |
| 6 | Обморок / истощение | `topicFarmerExhausted`, `topicPassedOutInTown`, `topicHarvey_MorningAfterExhaustion` |
| 7 | Страх грозы | `HasBuff buffStressThunder`, `HasConversationTopic topicHarveyStormStress`, `Weather: storm` |
| 8 | Терапия темноты | `HasQuest HarveyMod_DarknessStep*`, `topicDarknessTherapyStart`, `HasBuff buffDarknessLevel*` |
| 9 | Социальная тревожность | `HasBuff buffStressSocial`, `HasQuest HarveyMod_SocialRecovery`, `topicStressTreatmentSocialFollowup` |
| 10 | Переутомление | `HasBuff buffStressOverwork` / `buffStressTired`, `topicOverworkBreakActive` |
| 11 | Харви особенно тревожится | `topicHarvey_EscalatedCare`, `topicHarvey_NightRound*`, `HarveyMod_CareTrust_*`, `topicHarvey_ForcedHospitalization`, `HasBuff HarveyMod_Hospitalized` |
| 12 | Dating / Engaged / Married с Харви | `Relationship:Harvey` + любой gate выше (тон реакции меняется, не медицина Харви) |

**Не использовать для NPC-gate:** legacy `topicStressTreatment*Started`, `topicMineRescuePending`, `HarveyMod_CD_*` (короткий TTL).

## Приложение B: правила авторства реплик

1. **Длина:** 1–3 предложения; у Pam/George/Kent/Marlon — короче; у Elliott — можно чуть длиннее, без purple prose.
2. **Повторы:** `$1 letterId#first#nth` или `$c 0.5#variantA#variantB` — чтобы не надоедать за 3 дня topic.
3. **Hearts gating:** 0–2♥ — нейтрально/коротко; 6+♥ — теплее; 8+♥ — можно «ты» у peers (Sam, Abigail, Leah).
4. **Dating/Married overlay:** не отдельный файл на каждого NPC — второй блок `When: Relationship:Harvey: Dating, Married` с 1–2 строками **поверх** базовой реакции.
5. **Severity split для Abigail:** `When: HasBuff buffFracturedBone OR topicConcussion` → серьёзные строки; иначе — шутливые.
6. **Maru hard rule:** никогда не «вы и Харви такие милые»; максимум «он сегодня сосредоточен» / «следуй рекомендациям».
7. **Дети:** без hospital, blood, «умрёшь», war; Vincent — humor ok; Jas — quiet empathy.
