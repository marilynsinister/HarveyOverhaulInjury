## 1. Резюме

**Harvey Overhaul: Injury Logic** — SMAPI-мод для Stardew Valley, реализующий систему травм, лечения у Харви, осложнений и принудительной госпитализации. Мод является **логической (C#) частью** оверхaul-а Харви; контент (баффы, диалоги, события, письма) поставляется через **Content Patcher** в папке `HarveyOverhaul`.

Проект находится в **рабочем состоянии**: Release-сборка проходит успешно, DLL деплоится в `Stardew Valley/Mods/HarveyOverhaul/HarveyOverhaulInjury`.

Для дальнейшей доработки и работы с нейросетью подготовлена полная спецификация: [`docs/MOD_SPEC.md`](MOD_SPEC.md).

## 5. Реализованный функционал

### 5.1. Травмы (14 типов)

**Простые (лечение за один визит):**
- `buffHurt`, `buffBadlyHurt`, `buffSurgicalWound`

**Фазовые (2–3 стадии лечения):**
- `buffSprainedAnkle`, `buffBruisedRibs`, `buffBackStrain`, `buffDeepCuts`
- `buffBurnWounds`, `buffInfectedWound`, `buffTornMuscles`, `buffConcussion`
- `buffFracturedBone`, `buffShrapnelWounds`, `buffCold`

### 5.2. Источники травм

| Источник | Реализация |
|----------|------------|
| Боевой урон | `PlayerEventHandler.CheckHealthBasedInjuries` |
| Фарминг (инструменты + stamina) | `CheckFarmingInjuries` |
| Взрывы | `CheckExplosionInjuries` |
| Дождь / холод | `HandleRainLogic`, `CheckColdRisk` |
| Обморок | `PassOutHandler.TrackPassOut` |
| Шахта (загрязнение) | `HandleMinesLogic` |

### 5.3. Лечение

- Клик по Харви → `InteractionHandler`
- Начало лечения → `TreatmentManager.ApplyTreatmentForInjury`
- Смена фазы / выздоровление — только при флагах `ReadyForNextPhase` / `ReadyForRecovery`
- Ежедневная проверка фаз → `GameEventHandler.CheckInjuryPhases`

### 5.4. Осложнения (6 типов)

- `HarveyMod_WetBandage` — дождь / спа с повязкой
- `HarveyMod_WetStitches` — спа со швами
- `HarveyMod_DirtyWound` — шахта
- `HarveyMod_Neglect` — пропуск лечения ≥ 3 дней
- `HarveyMod_AllergicRash` — весна
- `HarveyMod_PainFlare` — гроза + тяжёлые травмы

Перерастание в `buffInfectedWound`: `ComplicationManager`.

### 5.5. Госпитализация

- Условия: `topicMineInjuryRescue` + Severe + `ForceHospitalization`
- Триггеры: вход в Hospital, proximity к Харви
- Мин. срок: 120 игровых минут (настраивается)
- 10 типов активностей каждые 20 мин → `HospitalActivityManager`

### 5.6. Шахта и спасение

- Запрет шахты при Severe → предупреждение → письмо → `HarveyMod_MineForbidden`
- Боевая смерть в Mine + отношения с Харви → CP-событие спасения
- Топик `topicMineInjuryRescue` → принудительная госпитализация

### 5.7. Сохранение и отладка

- Персистентное состояние: `InjuryState` / `DebuffState` через `StateManager`
- Снапшот баффов на конец дня, восстановление утром
- Debug HUD по **F10**
- Команды: `injury_reset`, `injury_debuff_add`, `injury_phase_*`

## 8. Архитектурные решения

| Решение | Обоснование |
|---------|-------------|
| Разделение C# / CP | Логика в SMAPI, контент в HarveyOverhaul CP |
| `DebuffState` в сохранении | Фазы, флаги готовности, независимо от игровых баффов |
| `AppliedTriggers` | Одноразовые триггеры, защита от дублей |
| Кулдаун 30 мин между травмами | Баланс, защита от спама при быстром уроне |
| Лечение по клику | Игрок контролирует темп, CP-диалоги по топикам |
| Снапшот баффов | Сохранение дебаффов мода между днями |
