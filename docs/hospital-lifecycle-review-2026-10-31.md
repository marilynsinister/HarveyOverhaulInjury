# Гибель, клиника и домашняя забота — исправления 31.10.2026

## Пустое окно после гибели

`hospitaldeath` показывает сообщение о штрафе и вставляет команду
`showItemsLost`. Закрытый `DialogueBox` уже не содержит текста. SMAPI может
увидеть его замену следующим меню в пределах одного кадра. Прежняя защита
диалогов Core считала такую смену вмешательством другого мода и могла вернуть
израсходованный объект окна после списка потерь.

Защита теперь запоминает событие и номер команды при открытии реплики.
Вернуть можно только непустое, незавершённое окно, которое не закрывается
и всё ещё принадлежит той же команде того же события. При восстановлении
возвращается `dialogueUp`; при смене команды/события сохранённое окно отбрасывается.

Сеансовый SMAPI-latest.txt при проверке был пустым. Механизм ошибки найден
по исходному коду мода и IL установленной игры; история конкретного сеанса
по логу не восстановлена.

## События, госпитализация и выписка

- Сцены ожидают окончания другого события, меню потерь, варпа и затемнения.
  Отложенные ID сохраняются и повторно проверяются, а не теряются на Warped.
- C# передаёт игре настоящий ID события и исходный ассет. В eventsSeen
  используется ID без условий из ключа Content Patcher.
- Незавершённое возрождение не обрабатывается посреди перехода или при
  принудительном завершении дня с ещё открытой сценой.
- Повторный запрос поступления сохраняет текущий срок и объяснение.
  Размещение в палате откладывается до завершения открытых окон.
- При дневном сне минуты, уже учтённые TimeChanged, не начисляются второй раз.
- Выбор выписки у Харви завершает стационар сразу. Очистка состояния снимает
  блокировку выхода, отложенные объяснения и сохранённый бафф госпитализации.
- Существующая ночная госпитализация засчитывается утром однократно.

## Повторы дома и кровать

Шесть вариантов домашних recovery-сцен теперь имеют условие `FALSE` для
обычного входа на карту: запускает их только Injury, который подбирает
версию и размещение. Так автоматический CP-запуск не расходится с флагами C#.

Один домашний визит завершает связанные запросы на спасение, выписку,
первый тяжёлый обход и последствия истощения. День визита сохраняется;
старые shown-day поля тоже учитываются при обновлении. Второго recovery-визита
в тот же день не будет. Новая помощь в будущий день остаётся доступной.

Для постановки используется `FarmHouse.GetPlayerBed().GetBedSpot()`, включая
переставленную кровать. Камера и оба участника получают абсолютные координаты;
Харви ищет свободную клетку рядом с учётом мебели. Фермерша лежит, а перед
выходом поза снимается. Если кровати или места рядом нет, сцена остаётся
отложенной. Текст после выписки согласован с действием уже у кровати.

## Записки

Три рецепта записок открываются утром в отношениях Dating/Engaged/Married
действием игры `MarkCraftingRecipeKnown`. Условия проверяют каждый неизвестный
рецепт отдельно, поэтому счётчики уже изготовленных записок сохраняются.
Запрашивающие записки письма больше не отправляются. Их старые ID и вложения
сохранены для уже поставленной очереди; тексты заменены обычными личными письмами.

проверка на сохранении не выполнялись. Тесты не изменяют пользовательские сейвы.
