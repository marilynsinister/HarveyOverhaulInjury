## ⚠️ Потенциальные проблемы

### Проблема 1: BuffManager.RemoveBuff() не работает?

**Гипотеза:** `_buffManager.RemoveBuff("HarveyMod_WetBandage")` не удаляет бафф.

**Проверить:**
- Что делает BuffManager.RemoveBuff()?
- Использует ли он правильный API Stardew Valley?
- Есть ли логирование для отладки?

### Проблема 2: Неправильный ID баффа?

**Проверка ID:**
```
Применение: "HarveyMod_WetBandage" (InjuryBuffs.WetBandage)
Удаление: "HarveyMod_WetBandage" (из complications)
```

✅ ID совпадают!

### Проблема 3: Удаление происходит РАНЬШЕ, чем бафф полностью применён?

**Гипотеза:** Бафф применяется с задержкой, и удаление происходит до того, как он "приклеился".

**НО:** Пользователь говорит, что дебафф "продолжил висеть", значит он УЖЕ ЕСТЬ.

### Проблема 4: Удаление вызывается ПОСЛЕ диалога?

**Проверка порядка:**
```
1. TreatAllComplications() [строка 282] ← Удаление ЗДЕСЬ
2. BuildCombinedDialogue() [строка 287] ← Диалог строится ПОСЛЕ
```

✅ Порядок правильный!

### Проблема 5: DelayedAction мешает?

**Проверка:**
```csharp
Game1.delayedActions.Add(new DelayedAction(1000, () => {
    _dialogueManager.Speak(harvey, combinedDialogue);

```

Диалог показывается С ЗАДЕРЖКОЙ (1000мс = 1 секунда).

НО! `TreatAllComplications()` вызывается ДО DelayedAction, сразу!

✅ НЕ должно быть проблемы.
