# ✅ ФИНАЛЬНАЯ СХЕМА РАБОТЫ (по вашей идее)

## 🎯 Основная логика

**Ваша идея:**
1. Игрок получает травмы в шахте
2. Теряет сознание → Событие спасения
3. Харви находит, везёт в госпиталь
4. Добавляется топик "ранен в шахте + потеря сознания"
5. Два триггера госпитализации:
   - A) Игрок в госпитале + топик + дебафф
   - B) Харви замечает (proximity) + топик + дебафф
6. Информативное сообщение о госпитализации

### 2. HandleHospitalLogic() - Триггер в госпитале

```csharp
private void HandleHospitalLogic()
{
    bool hasTopic = HasConversationTopic("topicMineInjuryRescue");
    bool hasCritical = HasAnyBuff(Severe);
    
    if (ForceHospitalization && hasTopic && hasCritical && !IsHospitalized)
    {
        StartForcedHospitalizationWithExplanation(injury, harvey, "mine_rescue");
        RemoveTopic("topicMineInjuryRescue");
    }
}
```

### 3. CheckHarveyProximity() - Триггер proximity

```csharp
private void CheckHarveyProximity()
{
    if (distance <= ProximityTiles)
    {
        bool hasTopic = HasConversationTopic("topicMineInjuryRescue");
        bool hasCritical = HasAnyBuff(Severe);
        
        if (ForceHospitalization && hasTopic && hasCritical && !IsHospitalized)
        {
            StartForcedHospitalizationWithExplanation(injury, harvey, "mine_rescue");
            RemoveTopic("topicMineInjuryRescue");
        }
    }
}
```

### 4. StartForcedHospitalizationWithExplanation()

```csharp
public void StartForcedHospitalizationWithExplanation(
    string injuryId, 
    NPC harvey, 
    string reason)
{
    IsHospitalized = true;
    MinimumStay = 120;
    
    WarpToHospitalBed();
    
    // Информативное сообщение с указанием срока
    if (reason == "mine_rescue")
    {
        string message = 
            "@! Твои раны после вчерашнего инцидента в шахте очень серьёзны.$a\n" +
            "Я не могу отпустить тебя в таком состоянии!$a\n" +
            "Ты остаёшься здесь под моим наблюдением минимум на 2 часа.$u\n" +
            "Я буду следить за твоим состоянием и обрабатывать раны.$l\n" +
            "Это не обсуждается.$a";
        
        ShowDialogue(harvey, message);
    }
    
    playSound("debuffHit");
}
```

## ✅ Преимущества схемы

1. **Топик как флаг:** Чёткий маркер "ранен в шахте + потеря сознания"
2. **Два триггера:** И в госпитале, и при встрече с Харви
3. **Информативность:** Харви объясняет ЧТО, ПОЧЕМУ и НАДОЛГО
4. **Автоматическое удаление:** Топик удаляется после срабатывания
5. **Нет повторов:** Проверка IsHospitalized предотвращает дубли
6. **Естественность:** Всё логично и реалистично
