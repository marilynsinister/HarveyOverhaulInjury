# Тон Харви по стадиям отношений

Краткий справочник для авторов диалогов и событий Harvey Overhaul.  
**Не заменяет** технические relationship gates в CP/C# — описывает только допустимый **тон речи**.

Шкала сердечек: 250 pts = 1♥ (vanilla).  
Стадии **Dating** и **Married** — отдельные relationship flags, не сводятся только к числу сердечек.

---

## 1. Таблица стадий


| Стадия             | Сердечки / gate                   | Роль Харви                             | Обращение и тон                                                                                                                                                                  |
| ------------------ | --------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Знакомство**     | 0–2♥, без dating                  | Врач / знакомый                        | «Вы» или очень осторожное «ты». Профессиональная дистанция, сочувствие без личной близости. **Без** ласковых обращений и pet names.                                              |
| **Дружба**         | 3–5♥, без dating                  | Настойчивый, но уважающий границы врач | Доверие, мягкая забота, «пациент / сосед». Может настаивать на осмотре, но формулировки — «рекомендую», «давай проверим». **Без** романтических обращений и телесной интимности. |
| **Близкая дружба** | 6–8♥, без dating                  | Близкий друг и опекун                  | Тревога сильнее, забота открытее. Допустимы «я рядом», «не хочу, чтобы с тобой что-то случилось». **Без** «люблю», «моя», pet names и супружеской опеки.                         |
| **Dating**         | `PLAYER_NPC_RELATIONSHIP Dating`  | Романтический партнёр                  | Романтическая забота, ревность в мягкой форме. Допустимы «солнышко», «малышка», объятия, ночные визиты, «мы вместе».                                                             |
| **Married**        | `PLAYER_NPC_RELATIONSHIP Married` | Муж                                    | Максимальная нежность и гиперопека. «Жена», «домой к нам», бытовая близость, «я жду дома». Тон теплее dating, меньше формальностей.                                              |


---

## 2. Запрещённые фразы до Dating

До стадии **Dating** (включая 6–8♥ без романтических отношений) **не использовать**:


| Фраза                         | Почему                                       |
| ----------------------------- | -------------------------------------------- |
| солнышко                      | Pet name, романтическая интимность           |
| моя дорогая                   | Притязание на романтическую близость         |
| малышка                       | Уменьшительно-ласкательное, партнёрское      |
| хорошая девочка               | Патронирующая интимность, не медицинский тон |
| я люблю тебя                  | Прямое романтическое признание               |
| я принял решение за нас обоих | Контроль без согласия партнёра               |
| без моего разрешения          | Авторитаризм, не «настойчивый врач»          |


> **Исключение:** экстренная медицинская сцена (обморок, reanimation) — допустимы короткие эмоциональные всплески («не уходи», «держись»), но **без** pet names и романтических обещаний.

## 3. Мягкие замены


| Вместо (до dating)                | Использовать                                                                   |
| --------------------------------- | ------------------------------------------------------------------------------ |
| солнышко / малышка / моя дорогая  | по имени, «ты», «фермер» (если уместно), «@»                                   |
| хорошая девочка                   | «молодец», «ты справилась», «так держать»                                      |
| я люблю тебя                      | «ты мне важна», «я переживаю за тебя», «мне не всё равно»                      |
| я принял решение за нас обоих     | «я настаиваю на осмотре», «давай сделаем так — для твоей же безопасности»      |
| без моего разрешения              | «пока я не буду уверен, что ты в порядке», «я не отпущу, пока не проверю»      |
| не обсуждается (авторитарно)      | «это не обсуждается — **с медицинской точки зрения**», «как врач, я настаиваю» |
| моя пациентка (риторика владения) | «мой пациент», «ты под моим наблюдением»                                       |
| я не отпущу (романтически)        | «я останусь рядом, пока ты не придёшь в себя»                                  |


### Примеры по стадиям

**0–2♥:** «Вы выглядите уставшей. Рекомендую отдохнуть и прийти на осмотр.»

**3–5♥:** «Ты снова переработала. Давай хотя бы измерим давление — я переживаю.»

**6–8♥ (без dating):** «Мне правда страшно, когда ты так рискуешь. Останусь рядом, пока не убедимся, что всё в порядке.»

**Dating:** «Солнышко, я не могу спокойно смотреть, как ты снова не спишь. Позволь мне позаботиться о тебе.»

**Married:** «Любимая, домой. Я уже жду — и не собираюсь отпускать тебя одну в такую ночь.»

## 4. Базовое правило

> **Харви может быть настойчивым, но не жестоким.**


| Настойчивость (OK)                     | Жестокость (не OK)                                            |
| -------------------------------------- | ------------------------------------------------------------- |
| Настаивает на осмотре, лечении, отдыхе | Унижает, давит страхом, лишает выбора без медицинской причины |
| Говорит прямо о рисках                 | «Без моего разрешения», «я решил за нас обоих»                |
| Эмоционален в экстренке                | Контролирует быт и свободу вне контекста травмы/здоровья      |
| Опекает с границами на ранних стадиях  | Pet names и «люблю» до dating                                 |


**Проверка перед коммитом текста:**  

1. Какая стадия отношений у игрока в этом событии?
2. Есть ли в репликах фразы из раздела 2?
3. Звучит ли настойчивость как забота врача/друга, а не как контроль партнёра?
