# Тон Харви по стадиям отношений

Краткий справочник для авторов диалогов и событий Harvey Overhaul.  
**Не заменяет** технические relationship gates в CP/C# — описывает только допустимый **тон речи**.

**Полный канон (CP):** в репозитории `HarveyOverhaul [CP]` — `docs/harvey-relationship-tone-guide.md`, раздел **«Заботливо-властная гиперопека»**.

Шкала сердечек: 250 pts = 1♥ (vanilla).  
Стадии **Dating** и **Married** — отдельные relationship flags, не сводятся только к числу сердечек.

---

## 0. Заботливо-властная гиперопека (характер мода)

**Цель:** Харви остаётся настойчивым, категоричным, берущим инициативу — но звучит **теплее и любовнее**, не как наказание.

- Любит фермершу; видит усталость, тревожность, склонность забывать о себе.
- Не может спокойно смотреть на риск здоровью.
- **Может** настаивать, запрещать, приносить еду/лекарства, проверять, идти с ней, делать за неё — **не жестоко**.
- **Не вычищать:** «я буду рядом», «я проверю», «сегодня отдыхаешь», «в шахту нельзя», «я сам принесу», «я не отпущу одну» (Dating/Married, опасные сцены, если тепло).
- **Смягчать грубое:** «Не спорь» → «Можешь спорить, но я всё равно попрошу прислушаться»; «Это не обсуждается» → «Обсудим потом. Сейчас — безопасность»; см. полную таблицу в CP-гайде.
- **Структура реплики:** заметил → риск → действие → смягчение любовью/тревогой/юмором → он всё равно добьётся заботы.
- **Не пассив:** не только «если захочешь». **Не жесток:** без унижения, угроз, пугающей опеки.

## 1. Таблица стадий


| Стадия             | Сердечки / gate                   | Роль Харви                             | Обращение и тон                                                                                                                                                                  |
| ------------------ | --------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Знакомство**     | 0–2♥, без dating                  | Врач / знакомый                        | «Вы». Профессиональная дистанция. **Настойчивость по протоколу** — без pet names и романтики.                                                                                   |
| **Дружба**         | 3–5♥, без dating                  | Настойчивый врач                       | «ты». Личная забота + **уверенная настойчивость по риску** («я настаиваю»), не только «рекомендую». Без романтики.                                                               |
| **Близкая дружба** | 6–8♥, без dating                  | Близкий друг и опекун                  | Тревога сильнее. «Я рядом», «я проверю», «я напомню» — OK. Без «люблю», «моя», pet names.                                                                                      |
| **Dating**         | `PLAYER_NPC_RELATIONSHIP Dating`  | Романтический партнёр                  | **Заботливо-властный:** «солнышко», настойчивость в любви, «я сам принесу», «сегодня не одна».                                                                                  |
| **Married**        | `PLAYER_NPC_RELATIONSHIP Married` | Муж                                    | Максимальная нежность + активная гиперопека. «Котёнок», «девочка моя» — точечно; властность обёрнута в любовь.                                                                  |

## 2. Запрещённые фразы до Dating

До стадии **Dating** (включая 6–8♥ без романтических отношений) **не использовать**:


| Фраза                         | Почему                                       |
| ----------------------------- | -------------------------------------------- |
| солнышко                      | Pet name, романтическая интимность           |
| моя дорогая                   | Притязание на романтическую близость         |
| малышка                       | Уменьшительно-ласкательное, партнёрское      |
| хорошая девочка               | Патронирующая интимность, не медицинский тон |
| я люблю тебя                  | Прямое романтическое признание               |


> **Исключение:** экстренная медицинская сцена — короткие эмоциональные всплески («не уходи», «держись»), но **без** pet names и романтических обещаний.

> **Не путать с грубой властностью:** «я настаиваю на осмотре», «сегодня без шахты» — **допустимо** на 3+♥, если без угроз и унижения.

## 3. Смягчение формулировок (не удаление настойчивости)


| Вместо (грубо)        | Использовать                                                                   |
| --------------------- | ------------------------------------------------------------------------------ |
| не спорь              | можешь спорить, но я попрошу прислушаться                                      |
| это не обсуждается    | обсудим потом; сейчас — безопасность                                           |
| я не дам              | я не позволю снова довести себя до такого                                       |
| всё под моим контролем | я уже всё подготовил — позволь мне помочь                                    |
| ты обязана            | я очень прошу; и да, буду настойчивым                                          |
| я решу за тебя        | я возьму это на себя, пока ты восстанавливаешься                               |
| никаких возражений    | возражения — после еды и перевязки                                             |
| ты слишком хрупкая    | ты быстро устаёшь; я вижу это раньше, чем ты признаёшь                        |
| солнышко / малышка (до dating) | по имени, «ты», «@»                                                    |
| я люблю тебя (до dating) | «ты мне важна», «я переживаю за тебя»                                    |


### Примеры по стадиям

**0–2♥:** «Вы выглядите уставшей. Я настаиваю — отдохните и зайдите на осмотр.»

**3–5♥:** «Ты снова переработала. Сегодня без шахты — я настаиваю. Давай хотя бы измерим давление.»

**6–8♥ (без dating):** «Мне страшно, когда ты так рискуешь. Я проверю и останусь рядом, пока не убедимся, что всё в порядке.»

**Dating:** «Солнышко, ты дрожишь. Чай и плед сейчас — спорить можно, но я всё равно настаиваю.$l»

**Married:** «Я люблю тебя слишком сильно, чтобы делать вид, будто не заметил. Садись — я сам принесу чай.$l»

## 4. Базовое правило

> **Харви заботливо-властный: настойчив, но не жесток.**


| Настойчивость (OK)                     | Жестокость (не OK)                                            |
| -------------------------------------- | ------------------------------------------------------------- |
| Настаивает, запрещает по риску, приносит, проверяет | Унижает, давит страхом-угрозой, «ты слишком слабая» |
| Берёт инициативу, если она упрямится | Каждая бытовая реплика — госпитализация                       |
| Категоричность + любовная обёртка (Dating/Married) | «Не спорь» / «не обсуждается» без смягчения                  |
| Pet names и «люблю» только Dating+   | Pet names и «люблю» до dating                                 |


**Проверка перед коммитом текста:**  

1. Какая стадия отношений у игрока в этом событии?
2. Есть ли запрещённые romance-маркеры до Dating (раздел 2)?
3. Харви **активен** в заботе, но не **жесток**?
4. Грубые формулировки заменены по разделу 3?
