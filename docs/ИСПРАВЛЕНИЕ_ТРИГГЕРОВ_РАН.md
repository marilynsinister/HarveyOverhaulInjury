### 2. ✅ Убрана прямая госпитализация

**Файл:** `InjuryManager.cs`, метод `ApplyBadlyHurt()`

#### Было (КОНФЛИКТ):
```csharp
public void ApplyBadlyHurt()
{
    _buffManager.AddBuff("buffBadlyHurt", -2);
    _dialogueManager.AddTopic("topicBadlyHurt", 8);
    Game1.playSound("debuffHit");
    
    // ❌ ПРЯМАЯ ГОСПИТАЛИЗАЦИЯ!
    if (_config.ForceHospitalization)
    {
        var harvey = HarveyHelper.FindHarvey(Game1.currentLocation);
        _hospitalizationManager.StartForcedHospitalization("buffBadlyHurt", harvey);
    }
}
```

**Проблема:** 
- Госпитализация запускалась БЕЗ объяснения
- Конфликт с новой системой через топики и proximity
- Обходилась логика событий спасения

#### Стало (ПРАВИЛЬНО):
```csharp
public void ApplyBadlyHurt()
{
    _buffManager.AddBuff("buffBadlyHurt", -2);
    _dialogueManager.AddTopic("topicBadlyHurt", 8);
    _dialogueManager.AddTopic("topicHealthDamageCritical", 8);
    Game1.playSound("debuffHit");
    
    // Примечание: Прямая госпитализация УБРАНА!
    // Харви заметит травму через proximity detection и запустит госпитализацию
    // с информативным сообщением через CheckHarveyProximity() или HandleHospitalLogic()
}
```

**Исправлено:**
- ✅ Травма применяется без немедленной госпитализации
- ✅ Госпитализация срабатывает только через proximity/hospital logic
- ✅ Всегда показывается информативное сообщение
- ✅ Соблюдается логика событий спасения

### 3. ✅ Упрощён PassOutHandler

**Файл:** `PassOutHandler.cs`, метод `OnPlayerWarped()`

#### Было (ДУБЛИРОВАНИЕ):
```csharp
bool wasInMine = LastPassedOutLocation.Contains("Mine");

if (wasInMine)
{
    _injuryManager.ApplyBadlyHurtSafe(); // ← Вызов 1
    _dialogueManager.AddTopic("topicMineInjuryRescue", 2);
}
else
{
    _injuryManager.ApplyBadlyHurtSafe(); // ← Вызов 2 (дубль!)
    Game1.playSound("debuffHit"); // ← Дубль (уже в ApplyBadlyHurt)
    Game1.addHUDMessage(...);
}
```

**Проблема:**
- `ApplyBadlyHurtSafe()` вызывался в ОБОИХ ветках
- Звук дублировался (в `ApplyBadlyHurt` уже есть `playSound`)
- Неоптимальный код

#### Стало (ЧИСТО):
```csharp
bool wasInMine = LastPassedOutLocation.Contains("Mine");

// Применяем критическую травму (всегда!)
_injuryManager.ApplyBadlyHurtSafe();

// Если в шахте - добавляем топик для события спасения
if (wasInMine)
{
    _dialogueManager.AddTopic("topicMineInjuryRescue", 2);
    _monitor.Log("💀 Добавлен топик: ранен в шахте + потеря сознания", LogLevel.Info);
}
else
{
    // Для обычных мест - показываем уведомление
    Game1.addHUDMessage(new HUDMessage("Ты чувствуешь себя очень плохо после потери сознания...", HUDMessage.error_type));
}
```

**Исправлено:**
- ✅ Травма применяется ОДИН раз
- ✅ Звук не дублируется
- ✅ Чистая логика: травма → топик (если шахта) → уведомление (если нет)

## 🔄 Полная цепочка обработки травм

### 1. Получение урона
```
OnUpdateTicked() (PlayerEventHandler.cs)
  ↓
CheckHealthBasedInjuries()
  ↓
health уменьшилось?
  ↓
ProcessDamageBasedInjuries(damage)
```

### 2. Проверка травм (по приоритету)
```
ProcessDamageBasedInjuries(damage)
  ↓
1. health <= 10? → Badly Hurt
2. damage >= 30 + Roll(5%)? → Fractured Bone
3. damage >= 20 + Roll(15%)? → Concussion
4. damage >= 15 + Roll(15%)? → Bruised Ribs
5. damage >= 10 + Roll(20%)? → Deep Cuts
6. damage >= 5 + Roll(25%)? → Hurt
7. Иначе → ничего
```

### 3. Применение травмы
```
ApplyXxxSafe()
  ↓
ApplyInjurySafe()
  ↓
Проверка: триггер уже применён? кулдаун?
  ↓
ApplyXxx()
  ↓
AddBuff() + AddTopic() + playSound()
```

### 4. Обнаружение Харви
```
CheckHarveyProximity() (каждый тик)
  ↓
Харви рядом + критический бафф?
  ↓
StartForcedHospitalizationWithExplanation()
  ↓
Информативное сообщение + госпитализация
```
