# 🔍 Цикл жизни дебаффа разорванных мышц (Torn Muscles)

## 📋 Обзор

**Травма:** Разорванные мышцы (`buffTornMuscles`)  
**Тип:** Тяжёлая травма (3 фазы)  
**Общая длительность:** 28 дней (7 + 14 + 7)

### Применение травмы

**Файл:** `Managers/InjuryManager.cs:493-503`

```csharp
public void ApplyTornMuscles()
{
    _buffManager.AddBuff("buffTornMuscles", -2);
    _dialogueManager.AddTopic("topicTornMuscles", 28);
    _dialogueManager.AddTopic("topicHealthDamageSevere", 28);
    Game1.playSound("debuffHit");

    // Инициализируем состояние дебаффа (3 фазы: 7 + 14 + 7 = 28 дней)
    int currentDay = (int)Game1.stats.DaysPlayed;
    _stateManager.CreateDebuffState("buffTornMuscles", currentDay, 7, 14, 7);
}
```

**Что происходит:**
1. Добавляется бафф `buffTornMuscles` с уровнем -2
2. Добавляется топик `topicTornMuscles` на 28 дней
3. Добавляется топик `topicHealthDamageSevere` на 28 дней
4. Воспроизводится звук `debuffHit`
5. Создаётся состояние дебаффа с параметрами:
   - `CurrentPhase = 0` (нелеченная травма)
   - `Phase1Duration = 7`
   - `Phase2Duration = 14`
   - `Phase3Duration = 7`
   - `TotalPhases = 3`
   - `TreatmentStarted = false`

## 2. Обнаружение травмы Харви

### Проверка наличия травмы

**Файл:** `EventHandlers/InteractionHandler.cs:74-106`

```csharp
// Проверяем наличие травм ПО СОСТОЯНИЯМ (DebuffState)
var activeDebuffs = _stateManager.GetAllActiveDebuffStates();

// Фильтруем только дебаффы этого мода (не включаем внешние дебаффы типа стресса)
var modDebuffs = activeDebuffs.Where(d => d.BuffId.StartsWith("buff")).ToList();

// Определяем основную травму (самую приоритетную)
string? mainInjury = modDebuffs
    .Where(d => _buffManager.HasBuff(d.BuffId))
    .OrderByDescending(d => GetInjuryPriority(d.BuffId))
    .FirstOrDefault()?.BuffId;
```

**Приоритет травмы:**
- `buffTornMuscles` = 60 (средний приоритет среди тяжёлых травм)

    {

        if (!_dialogueManager.HasTopic(phaseTopicId))

        }

**Что происходит:**

   - `TreatmentStarted = true`

   - `PhaseStartDay = currentDay`
   - `HarveyConversationHappened = true`

**Диалог:** Берётся из топика `Treat_TornMuscles_Before` (первый раз) или `Treat_TornMuscles_After` (повторно)

## 🐛 Потенциальные проблемы

### 1. ⚠️ Множественные дебаффы
**Проблема:** Если есть несколько травм, обрабатывается только основная (самая приоритетная).

**Решение:** ✅ Исправлено - теперь `InteractionHandler` проверяет все активные дебаффы и лечит их все сразу.

### 2. ⚠️ Внешние дебаффы
**Проблема:** Дебаффы от других модов могут мешать обработке.

**Решение:** ✅ Исправлено - фильтруем только дебаффы, начинающиеся с `buff`.

### 3. ⚠️ Диалоги не переписываются
**Проблема:** Ранее диалоги создавались в коде, а не брались из топиков.

**Решение:** ✅ Все диалоги берутся из файлов JSON через `DialogueManager`.
