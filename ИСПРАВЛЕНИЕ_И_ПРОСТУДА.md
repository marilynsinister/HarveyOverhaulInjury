# ✅ Исправление мокрой повязки + Система простуды

## 🔴 Проблема №1: Мокрая повязка не удаляется

### Анализ проблемы

**Пользователь сообщил:** "Харви сказал, что меняет повязку, но дебафф продолжил висеть"

**Причина:** Логирование было слишком тихим (`LogLevel.Trace`), и мы не видели, удаляется ли бафф на самом деле.

---

### ✅ Решение №1: Улучшенное логирование

**Файл:** `BuffManager.cs`, метод `RemoveBuff()`

#### Было:
```csharp
public void RemoveBuff(params string[] ids)
{
    foreach (string id in ids)
    {
        bool hadBuff = Game1.player.hasBuff(id);
        Game1.player.buffs.Remove(id);
        bool stillHas = Game1.player.hasBuff(id);
        
        _monitor.Log($"🗑️ RemoveBuff({id}): до={hadBuff}, после={stillHas}", LogLevel.Trace); // ❌ НЕ ВИДНО!
    }
}
```

#### Стало:
```csharp
public void RemoveBuff(params string[] ids)
{
    foreach (string id in ids)
    {
        bool hadBuff = Game1.player.hasBuff(id);
        
        if (!hadBuff)
        {
            _monitor.Log($"⚠️ RemoveBuff({id}): бафф не найден (уже удалён?)", LogLevel.Warn);
            continue;
        }
        
        Game1.player.buffs.Remove(id);
        bool stillHas = Game1.player.hasBuff(id);
        
        if (stillHas)
        {
            _monitor.Log($"❌ RemoveBuff({id}): ОШИБКА! Бафф НЕ УДАЛЁН!", LogLevel.Error);
        }
        else
        {
            _monitor.Log($"✅ RemoveBuff({id}): успешно удалён", LogLevel.Info); // ✅ ВИДНО!
        }
    }
}
```

**Преимущества:**
- ✅ Логирование на уровне `Info` - ВИДНО в консоли
- ✅ Отдельная проверка успеха/неудачи
- ✅ Предупреждение если бафф не найден
- ✅ Ошибка если бафф не удалился

```csharp
private void HandleRainLogic()
{
    int currentDay = Helpers.GameUtils.Today();
    
    // Сбрасываем счётчик в новый день
    if (_stateManager.State.LastRainDay != currentDay)
    {
        _stateManager.State.TotalTimeUnderRainToday = 0;
        _stateManager.State.LastRainDay = currentDay;

    // Общий счётчик времени под дождём
```

#### 4. Проверка риска простуды

```csharp
private void CheckColdRisk(int totalSecondsToday)
{
    if (_buffManager.HasBuff(InjuryBuffs.Cold)) return; // Уже простужен
    
    // Пороги (в секундах):
    double coldChance = totalSecondsToday switch
    {
        < 300 => 0.0,    // < 5 мин: безопасно
        < 600 => 0.05,   // 5-10 мин: 5%
        < 900 => 0.20,   // 10-15 мин: 20%
        < 1200 => 0.50,  // 15-20 мин: 50%
        _ => 0.80        // 20+ мин: 80%
    };
    
    if (coldChance > 0 && Helpers.GameUtils.Roll(coldChance))
    {
        _monitor.Log($"🤧 Игрок простудился после {totalSecondsToday / 60} минут под дождём", LogLevel.Warn);
        
        _injuryManager.ApplyColdSafe();
        Game1.addHUDMessage(new HUDMessage("Ты простудился! Нужно к врачу...", HUDMessage.error_type));
    }
}
```

#### 5. Применение простуды

**Файл:** `InjuryManager.cs`

```csharp
public void ApplyCold()
{
    _monitor.Log("🤧 Применяем простуду (Cold)", LogLevel.Info);
    
    _buffManager.AddBuff(InjuryBuffs.Cold, -2);
    _dialogueManager.AddTopic(ConversationTopics.Cold, 7);
    Game1.playSound("debuffHit");
    
    // 2 фазы: 3 дня острая + 4 дня восстановление = 7 дней
    int currentDay = (int)Game1.stats.DaysPlayed;
    _stateManager.CreateDebuffState(InjuryBuffs.Cold, currentDay, 3, 4, 0);
    
    Game1.addHUDMessage(new HUDMessage("Простуда! Температура, слабость...", HUDMessage.error_type));
}

public void ApplyColdSafe()
{
    ApplyInjurySafe(InjuryBuffs.Cold, ApplyCold, "{{ModId}}_triggerCold");
}
```
