# 🔴 Обнаруженные проблемы в триггерах получения ран

## Проблема 1: Неправильный приоритет проверок

### Текущий код (PlayerEventHandler.cs, строки 336-378):

```csharp
private void ProcessDamageBasedInjuries(int damage)
{
    // 1. Hurt (15-50 урона, 25% шанс)
    if (Between(damage, 15, 50) && Roll(0.25)) {
        ApplyHurtSafe();
        return; // ❌ СТОП! Дальше не проверяем!
    }
    
    // 2. Badly Hurt (критическое здоровье)
    if (health <= 10) {
        ApplyBadlyHurtSafe();
        return;
    }
    
    // 3. Bruised Ribs (15-25 урона, 15% шанс)
    if (Between(damage, 15, 25) && Roll(0.15)) {
        ApplyBruisedRibsSafe();
        return;
    }
    
    // 4. Deep Cuts (10-20 урона, 20% шанс)
    // 5. Concussion (20-45 урона, 15% шанс)
    // 6. Fractured Bone (30-50 урона, 5% шанс)
}
```

### ❌ Что не так:

**Сценарий:**
```
Игрок получает 45 урона от сильного удара
  ↓
Проверка 1: damage=45, Between(15,50)? ✅ Да, Roll(0.25)? ✅ Сработало!
  ↓
ApplyHurtSafe() → ЛЁГКАЯ травма!
return; ← ВЫХОД
  ↓
Concussion (20-45 урона) НЕ ПРОВЕРИЛОСЬ! ❌
Fractured Bone (30-50 урона) НЕ ПРОВЕРИЛОСЬ! ❌
```

**Проблема:** Лёгкая травма блокирует серьёзные!

## Проблема 2: Конфликт с госпитализацией

### InjuryManager.cs, строки 354-366:

```csharp
public void ApplyBadlyHurt()
{
    _buffManager.AddBuff("buffBadlyHurt", -2);
    _dialogueManager.AddTopic("topicBadlyHurt", 8);
    
    // ❌ ПРЯМАЯ ГОСПИТАЛИЗАЦИЯ!
    if (_config.ForceHospitalization)
    {
        var harvey = HarveyHelper.FindHarvey(Game1.currentLocation);
        _hospitalizationManager.StartForcedHospitalization("buffBadlyHurt", harvey);
    }
}
```

### ❌ Что не так:

**Конфликт с новой логикой:**
- Мы создали систему с топиком `topicMineInjuryRescue`
- Госпитализация должна срабатывать ТОЛЬКО когда Харви замечает
- Но `ApplyBadlyHurt()` запускает госпитализацию СРАЗУ!

**Два потока госпитализации:**
```
1. PassOutHandler → ApplyBadlyHurtSafe() 
   → ApplyBadlyHurt() 
   → StartForcedHospitalization() ← Сразу!

2. Наша новая система:
   topicMineInjuryRescue 
   → Харви замечает 
   → StartForcedHospitalizationWithExplanation() ← С объяснением!
```

**Результат:** Первая госпитализация запустится БЕЗ объяснения!

## Проблема 5: Перекрывающиеся диапазоны урона

### Текущие диапазоны:

```
Hurt:           15-50 урона (25% шанс)
Bruised Ribs:   15-25 урона (15% шанс)
Deep Cuts:      10-20 урона (20% шанс)
Concussion:     20-45 урона (15% шанс)
Fractured Bone: 30-50 урона (5% шанс)
```

### ❌ Что не так:

**Урон 20:**
- Может быть: Hurt, Bruised Ribs, Deep Cuts, Concussion
- Но проверится только Hurt (первый в списке)!

**Урон 45:**
- Может быть: Hurt, Concussion, Fractured Bone
- Но проверится только Hurt!

**Урон 10:**
- Может быть: Deep Cuts
- Но НЕ проверится (Hurt требует >= 15)
- Deep Cuts проверяется 4-м по счёту, но до него не дойдёт!

## ✅ Правильная логика

### Принцип: От серьёзных к лёгким

```csharp
private void ProcessDamageBasedInjuries(int damage)
{
    // 1. КРИТИЧЕСКИЕ (приоритет!)
    if (Game1.player.health <= 10) {
        ApplyBadlyHurtSafe();
        return;
    }
    
    // 2. ТЯЖЁЛЫЕ (большой урон)
    if (damage >= 30 && Roll(0.05)) {
        ApplyFracturedBoneSafe();
        return;
    }
    
    if (damage >= 20 && Roll(0.15)) {
        ApplyConcussionSafe();
        return;
    }
    
    // 3. СРЕДНИЕ
    if (damage >= 15 && Roll(0.15)) {
        ApplyBruisedRibsSafe();
        return;
    }
    
    if (damage >= 10 && Roll(0.20)) {
        ApplyDeepCutsSafe("combat");
        return;
    }
    
    // 4. ЛЁГКИЕ (последние!)
    if (damage >= 15 && Roll(0.25)) {
        ApplyHurtSafe();
        return;
    }
}
```

### Ключевые изменения:

1. **Приоритет по серьёзности:** Fractured Bone → Concussion → Bruised Ribs → Deep Cuts → Hurt
2. **Меньше перекрытий:** Проверка >= вместо Between
3. **Критические первыми:** health <= 10 проверяется в начале
4. **Больше урон = больше шанс серьёзной травмы**
